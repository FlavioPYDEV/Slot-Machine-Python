📜 Slot Machine Casino - Projeto de Estudo em Python
Python 3.8+
Status: Completo

Um simulador de máquina caça-níqueis desenvolvido em Python como projeto de estudo, implementando conceitos de programação orientada a objetos, tratamento de entrada e lógica de jogos.

✨ Funcionalidades Principais
🎰 Sistema completo de máquina caça-níqueis com 5 símbolos diferentes

💰 Gerenciamento de saldo do jogador

📊 Sistema de progressão com níveis e XP

🏆 Multiplicadores de prêmio variados por símbolo

📜 Histórico das últimas 10 jogadas

🎨 Animação durante o giro dos rolos

📱 Menu interativo com várias opções

📦 Requisitos
Python 3.8+

Nenhuma dependência externa necessária

🚀 Como Executar
Clone o repositório: git clone https://github.com/FlavioPYDEV/Slot-Machine-Python

Navegue até o diretório do projeto: cd Slot-Machine-Python

Execute o jogo: python main.py

🕹️ Como Jogar
Inicie o jogo e receba seu saldo inicial de $1000

Escolha quantas linhas deseja apostar (1-3)

Defina o valor da aposta para cada linha (
1
−
1−100)

Pressione Enter para girar os rolos

Ganhe prêmios quando símbolos iguais alinharem nas linhas apostadas

Acompanhe seu progresso e suba de nível

📊 Sistema de Pagamentos
Símbolo	Multiplicador	Frequência
7	10x	Raro
A	5x	Baixa
B	4x	Média
C	3x	Alta
D	2x	Muito Alta
Bônus: Linhas completas do mesmo símbolo dão +50% no prêmio!
